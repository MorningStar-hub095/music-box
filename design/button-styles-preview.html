♪ Midnight Galaxy · 按钮图标风格对比

三种图标风格 · 同一套玻璃质感按钮 · 主色填充 / 主色玻璃 / 心形收藏

风格 A · 精致化 emoji
零依赖 · 轻量
继续使用 Unicode 字符（▶ ⏸ ♥ ♪ ☰ 📊），但通过 drop-shadow 滤镜加阴影/发光，hover 时放大并增加光晕。 优点：实现简单，0 依赖，emoji 自带色彩感。 缺点：跨平台显示不一致（Windows/Mac/Linux 字形不同），无法精细控制线条粗细。
风格 B · SVG 线性图标
推荐 · 一致性最强
使用内联 SVG，线条粗细可调（1.8px → 2.2px）、颜色可控、与玻璃质感完美融合。 优点：跨平台一致、动效平滑、可主题切换、专业感强（参考 Apple Music / Spotify）。 缺点：需要预定义图标库，代码量稍多。
风格 C · 极简线性 glyph
高阶 · 最简洁
使用 CSS 伪元素绘制极简几何图形（三角/双竖线/箭头/心形），无 SVG 无 emoji。 优点：极致简洁、加载最快、几何美感强。 缺点：复杂图标（如频谱、搜索）难以表达，实现成本最高。
对比说明：
• 风格 A（精致化 emoji）：保留现有 Unicode 字符，加滤镜光晕。零迁移成本，但跨平台显示有差异。
• 风格 B（SVG 线性图标）：跨平台一致、线条精细可控、动效平滑。专业音乐 App 的主流选择，与玻璃质感融合度最高。
• 风格 C（极简 glyph）：几何极简，但复杂图标难以表达，且实现成本最高。

建议：风格 B（SVG 线性图标），原因：跨平台一致、专业感强、与 Midnight Galaxy 主题最契合。
