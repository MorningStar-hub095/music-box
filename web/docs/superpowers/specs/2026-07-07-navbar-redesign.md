# 导航栏重构设计文档

## 概述
将底部控制栏从单行三栏布局升级为双行布局，整合所有功能按钮，并移除顶部导航栏的品牌图标。

## 布局变更

### 移除内容
- 顶部导航栏的品牌图标（`.brand-logo`）
- 顶部导航栏的品牌文字（`.brand-text`）
- 保留顶部导航栏的胶囊Tab组和主题按钮（移入底部）

### 底部导航栏双行布局

#### 第一行：功能按钮行
从左到右排列：
1. **胶囊Tab组**（播放/收藏/最近）- 移自顶部导航
2. **收藏按钮**（HeartIcon）- 移自 action-row
3. **歌词按钮**（MusicIcon）- 移自 action-row
4. **播放列表按钮**（ListIcon）- 移自 action-row
5. **频谱按钮**（BarChartIcon）- 移自 action-row
6. **主题按钮**（PaletteIcon）- 移自顶部导航

#### 第二行：播放控制行（保持三栏布局）
- **左侧**：迷你曲目卡（封面缩略图 + 标题/歌手）
- **中间**：播放控制按钮组（上一首/快退/播放暂停/快进/下一首）
- **右侧**：播放模式按钮 + 音量控制

## 视觉设计

### 毛玻璃风格
- **背景**：深色毛玻璃效果（`backdrop-filter: blur(20px)`）
- **按钮**：半透明圆形，悬浮时上移+发光
- **边框**：1px 半透明白色边框
- **阴影**：顶部柔和阴影，与内容区分隔

### 颜色方案
- **背景**：`rgba(10, 10, 20, 0.8)` 深蓝黑
- **按钮背景**：`rgba(255, 255, 255, 0.08)` 半透明白
- **按钮悬浮**：`rgba(255, 255, 255, 0.15)` + 主色发光
- **边框**：`rgba(255, 255, 255, 0.1)`

## 文件变更

### App.tsx
1. 移除 `.nav-brand` 相关 JSX（品牌图标+文字）
2. 将 `.action-row` 中的4个按钮移入 `.footer` 第一行
3. 将顶部导航的胶囊Tab组和主题按钮移入 `.footer` 第一行
4. 调整 `.footer` 结构为双行布局

### App.css
1. 移除 `.nav-brand`、`.brand-logo`、`.brand-text` 相关样式
2. 移除 `.action-row` 相关样式
3. 新增 `.footer-row-1` 样式（第一行功能按钮）
4. 调整 `.footer` 为 flex 列布局
5. 优化按钮悬浮/激活状态样式

## 响应式适配
- **720px 以下**：隐藏部分按钮文字标签，缩小按钮尺寸
- **480px 以下**：进一步简化，只显示图标

## 交互保持
- 所有按钮功能不变（收藏/歌词/播放列表/频谱/主题/播放模式/音量）
- 按钮激活状态样式不变（收藏变粉、频谱高亮等）
- 快捷键不变
