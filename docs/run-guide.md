# 音乐盒子 · 运行指南（2026-10-26 优化版）

本文档说明如何启动优化后的系统，以及在哪里体验本轮新增的四项功能。
当前状态：**后端 API 运行于 http://localhost:49200，前端运行于 http://localhost:49201，均已验证健康。**

---

## 一、快速启动（三选一）

### 方式 A：一键脚本（推荐日常使用）

```bat
:: 项目根目录下，双击或命令行运行：
start.bat              # 开发模式：自动构建并拉起 API(49200) + 前端(49201)
start.bat --prod       # 生产模式：完整构建后启动
start.bat --api-only   # 只启动后端
```

脚本会自行打开独立窗口，关闭窗口或运行 `stop.bat` 即可停止。

### 方式 B：手动两个终端（本次验证所用方式）

```bash
# 终端 1 —— 后端 API（先确保已构建）
cd server
npm run build        # 首次或代码变更后执行（输出 dist/）
npm start            # 等价于 node dist/index.js，监听 49200

# 终端 2 —— 前端（Vite 开发服务器，热更新）
cd web
npm run dev          # 监听 49201
```

> 开发时前端访问 **http://localhost:49201**；后端健康检查 **http://localhost:49200/api/health**。

### 方式 C：纯静态生产预览（不带热更新）

```bash
cd web && npm run build          # 产出 web/dist
cd ../server && npm start        # API 自带静态托管，直接访问 http://localhost:49200
```

## 三、界面结构（2026-10-26 重构后：Mineradio 式两层视图）

**首页信息流 ⇄ 播放态全屏**，启动即进入首页：

| 界面 | 内容与入口 |
|---|---|
| 🏠 **首页** | 问候语 + 继续听大卡 / 快捷入口（画像·AI电台·天气·歌单架）/ 每日推荐 / 最近播放 / 我的歌单 / 我的收藏 |
| 🎬 **播放态** | 点击任意曲目或按 **F** 进入：全屏粒子舞台 + 发光歌词 + 电影镜头；**ESC / F / 右上角退出** 回首页 |
| 🎚️ **迷你播放条** | 首页底部悬浮玻璃条：进度点击跳转、上下曲、收藏、双击封面进舞台 |
| 🎨 **视觉控制台** | 播放态右上角：星云流光/星河/星球轨道/禅境极简 4 套预设 + 4 存档槽 + 配置导出导入 |
| 🌤️ **天气电台** | 顶栏按钮或首页入口卡，城市输入 → 一键入队 |
| 🗂️ **3D 歌单架** | 顶栏/首页入口，拖拽浏览、点击切换歌单 |

顶层导航（顶栏）：品牌标识 + 搜索 + 导入/添加/缓存/评论/电台/天气 + 用户。

## 五、停止服务

- 一键脚本方式：关闭脚本打开的窗口，或运行 `stop.bat`
- 手动方式：在对应终端 `Ctrl+C`
- 后台任务方式（本次会话）：由会话托管，会话结束自动回收

## 六、已知事项（不影响核心体验）

1. **爬虫功能**（热 100 刷新等）依赖 Python `requests` 库，当前 Python 环境未安装 → 需要 `pip install requests` 后重启后端；不影响播放/推荐/天气/视觉。
2. 日志中可能出现 `URL 有效率 35.7%` 预警——这是历史音频外链自然失效，可用「修复 URL」功能或等定时任务自动刷新。
3. 若本机开了系统代理，浏览器访问 localhost 一般不受影响；curl 调试时加 `--noproxy '*'`。
4. Vite 默认只监听 IPv6 时，`npm run dev -- --host` 可绑定全部地址（本次已采用）。
