## 1. 背景与问题

### 1.1 改造前现状

搜索链路（三层）：

```
前端 shared/useSearch.ts（Web/小程序共享）
  ├─ 本地筛选：对当前播放列表做内存过滤（含拼音首字母匹配）
  └─ "在线搜索"按钮 → GET /api/search
        ↓
路由 search.routes.ts（限流 60 次/分钟）
        ↓
SearchController（参数消毒：长度截断/白名单排序字段/数字范围）
        ↓
EnhancedSearchService.searchSongs
  ├─ Prisma 查询本地 PostgreSQL（playable=true && archived=false）
  ├─ 拼音变体 OR 扩展（generatePinyinVariants）
  ├─ 内存相关性打分（标题精确/包含/前缀 100/80/90 分，歌手 60/40，专辑 20，拼音 50，热度 ≤20）
  └─ Redis 缓存 60s（SEARCH_RESULTS TTL）
```

**核心结论：改造前搜索 100% 只依赖本地数据库（664 首）。**

项目中存在两处"外部"能力但均未接入搜索模块：
- `radio/tools/searchExternal.ts`：网易云爬虫搜索（AI 电台专用）——合规风险高（与 YesPlayMusic 下架事件同类路径），`neteaseFallbackEnabled` 默认关闭，**不用于搜索**；
- `library/jamendo.service.ts`：Jamendo CC 授权曲库 API（client_id 已配置 `b50cfeff`）——仅用于批量导入（v1.4.5 导入 158 首），**未接入搜索**。

### 1.2 发现的存量 Bug（本次一并修复）

| Bug | 现象 | 修复 |
|---|---|---|
| suggestions 响应结构不匹配 | 后端 `/api/search/suggestions` 返回裸数组，前端读取 `data.data?.suggestions`，导致**搜索建议永远为空** | 后端改为返回 `{ suggestions: [...] }` 对齐前端契约 |

## 2. 目标与设计原则

1. **扩展线上搜索能力**：以 Jamendo（CC 授权、官方 API、audiodownload 链接持久有效）为唯一线上搜索源。不启用任何爬虫路径。
2. **本地优先，线上增量**：本地结果永远是主结果；线上结果只放**独立附加段**，不混入本地分页语义（`pagination.total` 仍只统计本地）。
3. **fail-open 降级**：线上任何故障（未配 client_id / 网络异常 / 慢响应超时）都降级为空结果 + 明确 reason，**绝不阻塞、绝不抛错影响本地响应**。
4. **全量兼容**：不加任何参数时，响应契约只增不改；`scope=local` 可显式退化为纯本地搜索（离线/合规场景）。
5. **合规可追溯**：线上结果携带 CC license 链接；如用户选择"加入曲库"，走 v1.4.5 已有的导入管线（四道校验 + audio_licenses 登记）。

## 4. 线上搜索服务设计（search-online.service.ts）

### 4.1 数据流

```
EnhancedSearchService.searchSongs(filters)
  │  scope != 'local' && q 非空 && online.enabled
  ├─→ searchOnline(q, scope)                    ← 与 Prisma 查询并行，互不阻塞
  │     ├─ scope=local → 短路返回（零开销）
  │     ├─ enabled=false → { available:false, reason:'online_disabled' }
  │     ├─ client_id 未配置 → { available:false, reason:'jamendo_client_id_missing…' }
  │     ├─ 进程 TTL 缓存命中（300s/200 条 LRU 淘汰）→ 直接返回
  │     └─ searchJamendoTracks({q, limit})      ← 内部 3 次退避重试抗 Jamendo 间歇空响应
  │           └─ Promise.race 硬超时闸门（timeoutMs，默认 3s）
  │                 ├─ 成功 → 映射 + 打分重排 → cacheSet → 返回
  │                 └─ 超时 → fail-open 空结果 + reason，同时后台续跑该 promise，
  │                           完成后回填进程缓存（下次同词直接命中）
  ↓
result.online = OnlineSection（独立附加段）
```

### 4.2 线上条目映射（与本地歌曲对象同构）

```typescript
interface OnlineTrack {
  id: string;            // 'jamendo-online:<jamendoId>'（与导入库 id 'jamendo:<id>' 命名空间隔离）
  title: string;
  artist: string;
  album?: string;
  albumCover?: string;
  audioUrl: string;      // Jamendo 流媒体/下载直链（stream 优先）
  duration?: number;     // 秒
  platform: 'jamendo';
  source: 'online';      // 线上标记，前端据此显示来源徽标
  audioKind: 'stream' | 'download';
  licenseUrl?: string;   // CC 授权页
}
```

无任何可播放链接的条目直接过滤；线上条目**不入库**，仅即时播放。若用户想永久收录，走已有 `POST /api/library/jamendo/import` 管线（下载 → 四道校验 → 入库 + license 登记）。

### 4.3 接口契约（响应示例）

`GET /api/search?q=jazz&scope=all`（默认）：

```json
{
  "success": true,
  "data": {
    "results": [ /* 本地结果，结构不变 */ ],
    "pagination": { "page": 1, "limit": 20, "total": 1, "total_pages": 1 },
    "searchInfo": {
      "query": "jazz", "fuzzy": true, "pinyinMatched": false, "duration": 1700,
      "sources": { "local": 1, "online": 10, "onlineAvailable": true }
    },
    "online": {
      "available": true, "source": "jamendo",
      "items": [ /* OnlineTrack[]，≤10 条 */ ],
      "duration": 1695
    }
  }
}
```

降级示例（Jamendo 慢响应触发 3s 闸门）：`online.available=false`，`reason="jamendo:timeout_3000ms"`，`items=[]`——本地结果正常返回。该降级结果 Redis 只缓存 5s，配合后台回填，下次搜索即可拿到线上结果。

新增端点 `GET /api/search/online?q=<关键词>`：强制只搜线上、不查本地库（探索新歌/本地无结果兜底场景）。

健康检查 `GET /api/search/health` 新增字段：`services.onlineSearch: "ok" | "stub" | "disabled"`。

## 5. 异常处理矩阵

| 故障场景 | 行为 | 用户感知 |
|---|---|---|
| JAMENDO_CLIENT_ID 未配置（stub） | `online.available=false`，reason 明确提示注册步骤 | 仅看到本地结果，无报错 |
| SEARCH_ONLINE_ENABLED=false | 全局短路，完全不触网 | 纯本地搜索（离线模式） |
| Jamendo 间歇空响应 | searchJamendoTracks 内部 3 次退避重试（800/1600ms 间隔） | 无感知 |
| Jamendo 慢响应（>3s） | 硬超时 fail-open + 后台回填缓存；降级结果短缓存 5s | 首次只看到本地结果，重试即有线上 |
| Jamendo API 5xx/网络断 | `reason="jamendo:api_http_500"` 等 | 仅本地结果 |
| 本地 DB 故障 | 原有 500 响应逻辑不变 | 原有提示 |
