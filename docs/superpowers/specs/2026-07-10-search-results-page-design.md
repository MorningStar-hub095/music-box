# 搜索结果页面设计文档

## 概述

本文档描述音乐播放器搜索结果界面的优化设计，将搜索结果从模态弹窗升级为独立全屏页面。

## 需求背景

### 问题描述
当前搜索结果以模态弹窗形式显示，存在以下问题：
1. 展示空间有限（max-width: 480px; max-height: 60vh）
2. 视觉层级不够清晰
3. 缺少加载状态反馈
4. 交互体验有待优化

### 用户需求
- 独立全屏页面展示搜索结果
- 优化交互体验（加载状态、悬停效果、点击行为）
- 明显的退出按钮

## 设计方案

### 方案选择
采用**独立全屏组件 + 状态提升**方案：
- 创建独立的 `SearchResultsPage` 组件
- 搜索状态通过 `useSearch` hook 管理
- 在 App.tsx 中条件渲染搜索页面

### 组件架构

```
App.tsx
  ├── 搜索栏（保持现有）
  ├── SearchResultsPage（新增，条件渲染）
  │   ├── 顶部栏（搜索词 + 关闭按钮）
  │   ├── 结果列表
  │   │   ├── 骨架屏（加载中）
  │   │   └── 歌曲项（带操作菜单）
  │   └── 空状态提示
  └── 主内容区（搜索时隐藏）
```

### 新增文件

1. **`web/src/components/SearchResultsPage.tsx`**
   - 搜索结果页面主组件
   - 接收搜索状态和回调函数
   - 渲染结果列表和操作菜单

2. **`web/src/components/SearchResultsPage.css`**
   - 全屏页面样式
   - 歌曲项样式
   - 操作菜单样式
   - 骨架屏动画

3. **`web/src/components/SkeletonLoader.tsx`**
   - 骨架屏占位符组件
   - 模拟歌曲项布局

### 修改文件

1. **`web/src/App.tsx`**
   - 添加 `showSearchResults` 状态
   - 搜索时显示 SearchResultsPage
   - 隐藏主内容区

## 交互设计

### 搜索结果项交互

```
鼠标悬停 → 背景色变化 + 显示操作按钮
点击歌曲 → 显示操作菜单（播放、加入播放列表、加入曲库）
操作菜单 → 半透明遮罩 + 居中弹窗
```

### 操作菜单选项

- **播放**：立即播放该歌曲
- **加入播放列表**：选择目标播放列表
- **加入曲库**：添加到本地曲库
- **取消**：关闭菜单

### 加载状态

- 显示5个骨架屏占位符
- 每个占位符模拟歌曲项布局（封面、标题、艺术家）
- 加载完成后淡出动画

### 退出方式

- 右上角关闭按钮（X图标）
- 点击背景区域关闭
- ESC键关闭

## 视觉设计

### 页面布局

```
┌─────────────────────────────────────┐
│  搜索结果 (10)              [X关闭] │  ← 顶部栏
├─────────────────────────────────────┤
│  ┌─────────────────────────────────┐│
│  │ [封面] 歌曲标题          [⋮]   ││  ← 歌曲项
│  │         歌手名称               ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │ [封面] 歌曲标题          [⋮]   ││
│  │         歌手名称               ││
│  └─────────────────────────────────┘│
│  ...                                │
└─────────────────────────────────────┘
```

### 样式规范

- **背景**：半透明毛玻璃效果
- **字体**：继承应用主题字体
- **间距**：使用 `--spacing-*` 变量
- **圆角**：使用 `--radius-*` 变量
- **动画**：淡入淡出 300ms

### 响应式设计

- **桌面**：全屏显示，最大宽度无限制
- **平板**：全屏显示，边距适当增加
- **手机**：全屏显示，触控区域优化

## 数据流

```
用户输入搜索词
  ↓
点击搜索按钮 / 按 Enter
  ↓
设置 showSearchResults = true
  ↓
SearchResultsPage 组件渲染
  ↓
显示骨架屏（加载中）
  ↓
useSearch hook 执行搜索
  ↓
搜索完成 → 渲染结果列表
  ↓
用户点击歌曲 → 显示操作菜单
  ↓
用户选择操作 → 执行对应逻辑
  ↓
关闭搜索页面 → 返回主界面
```

## 错误处理

### 网络错误
- 显示错误提示
- 提供重试按钮

### 无结果
- 显示空状态提示
- 提供搜索建议

### 超时
- 显示超时提示
- 提供重试按钮

## 性能指标

1. **页面切换延迟**：< 100ms
2. **骨架屏显示**：立即显示
3. **搜索结果加载**：< 3s
4. **操作菜单响应**：< 50ms
