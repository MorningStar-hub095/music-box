# Midnight Galaxy — 音乐播放器设计哲学

## 设计理念

**「Cosmic Resonance」** — 宇宙共鸣

音乐是宇宙的语言。每一个音符都是一颗星辰，每一段旋律都是一片星云。Midnight Galaxy 将音乐播放器化为一个微型宇宙——听众在星海中漂浮，与音乐产生共鸣。

## 色彩体系

### 深空背景
- 主背景：`#080B1A` — 深邃宇宙黑，几乎纯黑但带微弱蓝调
- 次背景：`#0F1228` — 略浅的星际蓝，用于卡片层次
- 表面：`#1A1D3A` — 星云紫蓝，用于交互元素

### 宇宙色彩
- 主色：`#6366F1` — 超新星蓝紫（Indigo），能量感与神秘感并存
- 主色亮：`#818CF8` — 星光紫
- 主色暗：`#4F46E5` — 深空蓝紫
- 辉光：`rgba(99, 102, 241, 0.4)` — 光晕效果

### 点缀色
- 高亮：`#FBBF24` — 恒星金（歌词当前行、激活状态）
- 收藏：`#F472B6` — 玫瑰星云粉
- 成功：`#34D399` — 翡翠星

### 文字层次
- 主文字：`#F8FAFC` — 星光白
- 次文字：`#94A3B8` — 星尘灰
- 弱文字：`#475569` — 暗物质灰

## 视觉特征

### 1. 星空粒子背景
- 全屏 Canvas 渲染 100-200 个微弱星点
- 星点缓慢闪烁（opacity 0.2-0.8 循环）
- 3-5 个较大的光晕缓慢漂移
- 主色调随当前歌曲 coverColor 微调

### 2. 玻璃星云卡片
- `backdrop-filter: blur(24px)` 深度模糊
- 背景 `rgba(26, 29, 58, 0.4)` 半透明星云色
- 边框 `1px solid rgba(255, 255, 255, 0.06)` 微光
- 阴影 `0 8px 32px rgba(0, 0, 0, 0.4)` 深空投影

### 3. 歌词 — 星轨展开
歌词不再用 3D 阶梯，而是「星轨」设计：
- 当前行：居中大字，恒星般发光，金色高亮
- 前一行：向上淡出，化为星尘飘散
- 下一行：下方半透明，像远方星辰若隐若现
- 切换动画：新行从下方「升起」如新星诞生，旧行「陨落」消散
- 背景：歌词区有微弱的星轨弧线装饰

### 4. 封面 — 星核
- 圆形或大圆角方形
- 播放时外圈光环脉动（类似行星环）
- 暂停时光环静止
- 封面图片有微妙的内发光

### 5. 控件 — 星辰按钮
- 播放按钮：圆形，主色渐变 + 外发光
- 辅助按钮：半透明圆形，hover 时光晕扩散
- 进度条：星轨弧线，已播放部分发光
- 音量：同进度条风格

### 6. 频谱 — 星际脉冲
- 柱状图改为渐变色（底部深紫 → 顶部亮蓝）
- 每根柱顶部有微弱光点
- 背景半透明深空色

## 字体

- 品牌/标题：`'SF Pro Display', -apple-system, sans-serif`，font-weight 700
- 正文：`'SF Pro Text', -apple-system, sans-serif`，font-weight 400
- 歌词当前行：font-weight 600，letter-spacing 0.5px
- 时间/数字：`'SF Mono', monospace`，tabular-nums

## 动画

- 星空粒子：`@keyframes twinkle` 3-5s 循环闪烁
- 封面光环：`@keyframes pulse-ring` 3s 呼吸
- 歌词切换：`@keyframes star-rise` 0.6s 升起 + 0.4s 淡出
- 按钮 hover：`box-shadow` 扩散光晕 0.3s
- 页面切换：`opacity` + `translateY` 0.3s 淡入
